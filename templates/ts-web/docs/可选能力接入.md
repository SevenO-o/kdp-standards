# 可选能力接入

模板 `ts-web@0.1.4` 提供本说明，默认仍为无配置、无存储的文本工具，没有空的上传按钮或设置页面。规范入口由初始化助手下载到 `docs/standards/README.md`，先读该入口和锁定版本；原始模板目录本身不包含规范快照。

## 涉及文件处理

从锁定规范 README 读取当前文件上传与下载专项， 实现需要的文件选择、上传、处理状态及下载。先确定格式/数量/大小、解码内存、批量策略和清理时机，再写接口 Schema、生成契约、实现页面及业务验证。使用适配平台路径前缀的相对 API 地址，不能依赖使用者的本地路径。

临时上传处理不等于平台持久文件能力；不跨请求保存时保持 `capabilities.files: false`。多阶段任务或历史存储须另行核对平台能力。真实文件经过实际入口上传、处理并下载打开，才能报告这条链路通过。

## 涉及参数、配置和 API Key

从锁定规范 README 读取当前配置与密钥专项， 区分单次业务参数、浏览器非敏感偏好、服务器普通配置和秘密。单次参数通过接口传递即可；跨重启保留的配置需要平台版本化存储。API Key 声明在 `secrets`，不写值到项目，不通过 `VITE_*` 传给前端。

README 写明配置名、用途、是否必填、格式、非敏感默认值、允许的外部目标与生效方式。只开发后端适配边界；本地秘密由所有者私密设置，不要求用户交给 Agent。模板不自动加载 `.env.local`，如需该方式须在后端明确接入并遵守打包排除要求。

发布前核对可信平台配置能力与加密连接；支持时由助手自动同步已声明环境值并绑定配置修订，工具后端从环境读取。普通无配置工具保持两数组为空。工具运行允许联网，构建仍无网络；实际供应商连通另行验证。不得把工具 HTTP 网页当作秘密输入通道，不增加虚构同步按钮或将 Key 写进镜像。

## 条件验收记录

工具 README 按实际需求记录适用项：文件入口和限制、结果下载与清理、单次参数校验、配置保存/同步/生效状态，以及尚缺的平台能力。不适用的项标为不适用；未实施不能标为通过。静态检查通过之后，仍须完成相关专项规范列出的行为验证。
