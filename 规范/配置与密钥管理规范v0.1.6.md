# 配置与密钥管理规范 v0.1.6

属于规范包 0.1.9。本页完整说明声明、本地设置、发布同步、隐藏输入、加密保存和后端环境注入，无需阅读历史版本。启用前确认可信平台 `configuration.enabled=true`、`configuration.injection=environment-v1`，以及助手实际支持的连接与命令；规范存在不代表目标平台已经验收。

## 配置分类

| 类别 | 例子 | 本地与服务器处理 |
| --- | --- | --- |
| 单次业务参数 | 图片质量、目标尺寸、导出格式 | 随本次请求发送，服务端校验；不产生全局配置版本 |
| 非敏感界面偏好 | 排序方式、面板展开状态 | 可选保存在浏览器，支持清除；不能作为服务器权威配置 |
| 工具共享普通配置 | 固定模型名、允许的上游地址、业务阈值 | 本地开发单独保存；部署配置按工具与环境保存在服务器，版本化同步 |
| 业务秘密 | API Key、访问令牌、密码、签名私钥 | 本地私密保存，通过独立加密流程同步；服务器加密保存，只供获准后端使用 |
| 平台身份与系统变量 | 发布凭据、上下文签名密钥、PORT | 平台管理，不进入业务配置、不透传给工具使用者 |

匿名使用工具不等于有权维护共享设置。全局普通配置和密钥的管理接口必须校验工具所有者；不能仅在公开页面隐藏一个按钮。浏览器中的本次操作参数由业务规则限制，不能覆写全局密钥、上游授权目标或运行权限。

保留敏感名称后缀 `API_KEY`、`APIKEY`、`TOKEN`、`PASSWORD`、`SECRET`、`PRIVATE_KEY`、`CREDENTIAL`；以这些完整词组结尾的名称必须放在 `secrets`。检查器的名称检查不能识别所有秘密，改名不改变敏感性。

README 列出字段用途、必填性、格式/范围、非敏感默认值、上游目标、缺失行为与生效时机。`.env.example` 只使用空值或明显占位符。秘密不得进入源码、依赖锁、镜像层、构建参数、命令行参数、URL 查询、浏览器存储、日志、截图或下载结果。

## 1. 工具声明与本地设置

在 `kdp.json` 中声明字段，不填写真实值。例如配置片段：

```json
{
  "config": [{ "name": "TOOL_MODEL", "required": true }],
  "secrets": [{ "name": "TOOL_API_KEY", "required": true }]
}
```

名称必须为 `TOOL_` 加大写字母、数字或下划线，普通配置与秘密不能重名。API_KEY、TOKEN、PASSWORD 等敏感名称必须声明在 `secrets`。

用户通过本地私密编辑器或凭据助手设置项目根目录 `.env.local`，也可以设置启动发布助手的进程环境。不要要求用户将真实 Key 发到聊天。`.env.local` 建议权限 0600，必须本人所有，不能是符号链接、硬链接或其他用户可写文件，上限 256 KiB。

助手只读取 `.env.local` 和当前进程环境中的已声明字段：**进程环境优先，其次 `.env.local`**。文件按 Node.js dotenv 语法解析，不执行 shell 命令或变量插值，不自动读取其他 `.env` 文件。空值、控制字符、多行值、占位掩码或超过 16384 字符的值会拒绝同步。省略变量表示保留服务器已有值，空字符串不表示删除。

后端本地启动时也使用相同来源及优先级，例如：

```sh
node --env-file-if-exists=.env.local server/index.mjs
```

上例为启动方式示意，实际入口按工具构建结果填写。TypeScript 后端可将此 Node 参数加在现有开发命令中。模板不会自动为每个工具加载 `.env.local`，Agent 应在需要密钥的工具开发脚本中补齐加载。不要让前端读取 Key，也不要使用 `VITE_*` 或在构建时将 Key 替换进 JS。

## 2. 发布时自动同步

正常使用现有发布命令：

```sh
kdp publish --project /工具目录
```

助手完成源码检查、登记或核对原工具绑定、读取服务器配置基础版本、同步本地已声明值、绑定返回修订、上传源码及发布。本地和服务器都缺少必填值时，按第 5 节进行终端隐藏输入；无交互终端则报告缺失字段名。没有配置声明的旧工具继续原流程。

配置通过第 6 节规定的正常验证证书的 HTTPS 请求传输，不放进源码压缩包。配置同步成功后，新容器通过健康检查才切换入口。不会把整份本地环境、发布凭据或浏览器 Cookie 交给服务器工具。当前只支持按工具所有者保存的 `production` 配置；同一工具的所有访问者使用该工具的 Key。

本地未提供的已声明值保留；删除声明会从新修订移除该字段。需要删除仍声明的可选字段时，可使用高级配置命令明确提交 `null`；必填字段不能删除。更新本地 Key 后重新发布即可使用新值，不需要额外设置页面。修改本地文件不会自动影响运行中的工具。

发布前会持久化源码快照、幂等编号、配置基础版本、声明和本地值的校验指纹，不持久化明文 Key。请求中断时重新执行 `publish`，恢复同一次发布。同步尚未确认时须保留相同本地环境值；值发生变化会报告 `ENVIRONMENT_CHANGED`，恢复原值后重试。配置已同步并保存修订指针后，恢复发布不再读取本地 Key。已明确拒绝的配置冲突会结束该次本地尝试，下次发布重新读取基础版本；结果不明不会创建替代操作。

助手不会在输出中展示同步值。原来的 `config --input-file`、`--activate`、`--revoke-version` 及 `publish --config-revision` 仍可用于高级维护，详细命令见 [高级配置及固定目标代理接入](固定目标代理接入v0.1.1.md) 第 2 节；日常发布无需使用。

## 3. 服务器存储与运行注入

秘密使用 AES-256-GCM 加密保存，认证数据绑定所有者、工具、production 环境、名称和秘密版本，主密钥独立于数据库及源码存储。不可变 `configRevisionId` 绑定普通配置、秘密版本和可选代理目标，管理查询仅返回秘密状态。

默认将未绑定代理目标的秘密注入对应工具容器的环境变量。工具后端使用相同代码：

```ts
const apiKey = process.env.TOOL_API_KEY;
if (!apiKey) throw new Error('缺少 TOOL_API_KEY');
// 在后端将 apiKey 传给所用 LLM SDK，或用于经过业务校验的 HTTPS 请求。
```

工具无需实现密钥上传、加密或平台签名客户端。API 负责解密；执行器不持有主密钥，数据库角色不能读取密文列。执行器在构建完成后，通过 HTTPS、发布专属签名及状态验证获取这一发布的秘密，再通过 Docker 子进程环境和 `--env NAME` 注入。值不进入命令行参数、镜像构建阶段或平台业务日志。运行恢复会核对实际容器环境与绑定修订。

`POST /runtime/v1/environment` 只接受发布 ID、30 秒内时间戳和独立用途的 HMAC 签名；只能读取仍持有租约的当前候选或当前成功发布。管理凭据不能单独调用该接口。它返回该发布的环境秘密，工具后端持有自己的签名上下文，因此同样能取得自身已获授权的环境秘密；不能读取其他发布或已撤销版本。平台运行签名不能暴露给浏览器或第三方。

环境注入意味着工具进程和有该 Docker daemon 管理权限的维护者能读取 Key，包括容器检查结果。不要将完整环境或 Docker inspect 原始结果转交使用者。构建产物中不包含 Key；这不意味着运行时容器元数据中没有 Key。

## 4. 外连与生命周期

工具可以直接使用 LLM SDK、流式调用或后端 HTTPS，沿用每工具 bridge、开放出口、回环入站与资源限制。默认直接外连不经过平台代理的目标白名单、次数配额和反射检查。业务代码须校验 URL 来源、模型和费用相关参数，避免暴露任意转发入口。

需要固定目标、平台计数和平台代理注入时，可以选择 [固定目标代理接入](固定目标代理接入v0.1.1.md)。已有目标绑定的秘密保持代理专用，不注入环境；自动发布保留仍被声明的目标。切换方式时必须显式调整目标绑定和工具代码。

更新与回滚都使用发布绑定的配置版本；已撤销秘密不能用于新发布、激活、恢复或再次从平台获取。**环境变量已经进入进程后，平台撤销不能抹掉该进程中的旧值**：立即停用需要在供应商撤销 Key，并停止或用新配置替换现有容器。平台代理模式继续在每次新调用前检查撤销状态。平台撤销不是供应商撤销，已发送请求可能完成。

## 5. 发布时隐藏输入

执行通常的发布命令：

```sh
kdp publish --project /工具目录
```

取值顺序为当前进程环境、项目 `.env.local`、服务器已有配置；本地值优先同步，服务器已有值在本地省略时沿用。只有两边都缺少的必填字段才提示填写。可选字段不会主动询问，已撤销的服务器 Key 不视为可用值。

```text
请输入 TOOL_API_KEY 的 Key（不回显，Ctrl+C 取消）：
```

普通配置和秘密均不回显。支持粘贴单行值、退格和 Ctrl+U 清空；空值或占位掩码会重新提示。Ctrl+C、Ctrl+D、终端断开或终止信号会取消输入，并恢复终端输入模式；多行粘贴和不支持的控制字符会拒绝，不把剩余文本用于下一个字段。

输入仅保留在当前助手进程内存，通过既有配置通道同步到服务器，不写回 `.env.local`、源码、镜像、助手状态文件或命令历史。全部必填项收集完毕后才提交配置。取消时可能已完成工具登记，但不会提交未完成的配置或创建新发布任务。

### Agent 与非交互执行

提示显示在终端 stderr，stdout 保持结构化结果。需要 stdin 和 stderr 都连接真实 TTY；不会从管道读取 Key。无交互终端时返回 `CONFIG_INPUT_REQUIRED`，提示缺失字段名，不一直等待。

自动化可以显式禁用交互：

```sh
kdp publish --project /工具目录 --non-interactive
```

配置齐全时照常发布；缺少必填项时失败。Agent 应把同一条发布命令交给用户在交互终端执行，或指导用户通过私密编辑器设置本地环境，不能要求把真实 Key 发到聊天，也不能代填到命令参数中。

### 交互中断与重试

同步前仍保存固定的幂等键、基础修订、源码快照与值的校验指纹；新增记录只包含交互字段的名称和分类，不保存输入值。

如果同步响应丢失或进程退出，重新执行 `publish` 会要求再次输入相同值；也可以在本地环境中提供原值。输入不同值时返回 `ENVIRONMENT_CHANGED`，不替换结果尚未确认的请求。已经确认并保存配置修订后，继续发布不会再次询问 Key。

本次输入方式对已有配置工具兼容，不改变服务器协议，不自动重新部署工具。默认交互只补缺失的必填字段，不提供交互覆盖已有 Key 的独立命令；替换现有 Key 仍可通过本地环境更新后发布，或使用已有高级配置接口。

## 6. 加密连接

维护者可在同服务器开启独立 HTTPS API，同时保留网页和工具的 HTTP 地址。公司安装包提供 `api-transport.json`，包含固定的 HTTPS 地址及公开证书，安装器写入用户的可信 bootstrap。证书仅用于助手 API 请求，不写入系统或浏览器 CA，不来自工具源码、工具环境或服务器动态响应。

助手校验证书有效期、IP、证书链与固定平台主机，所有发布 API 请求均走该连接；拒绝重定向，失败不回退 HTTP，拒绝关闭 TLS 校验的环境。发布者凭据继续绑定原平台来源，升级助手不更换所有者。

首次安装包必须由公司可信渠道取得并核对维护者给出的摘要；公开下载地址本身不建立信任。证书更新需维护者分发并安装新包，不自动信任服务端返回的新证书。

未配置专用连接时可以使用正常验证的原生 HTTPS。仅 HTTP 的连接会在输入前拒绝同步秘密；`--allow-intranet-http`、代理转发头和关闭 TLS 验证都不能替代加密连接。工具网页保持 HTTP 不表示可以从该网页收集真实 Key。

## 7. 访问边界与验收

当前配置为工具所有者维护的共享 `production` 配置；所有匿名访问者在业务权限内使用同一工具 Key，不能读取或修改它。若要每个同事保存自己的 Key，先具备可识别身份和个人秘密隔离，不使用 `intranet-visitor` 冒充个人身份。用户自带 Key 的单次临时模式须单独设计并使用加密通道，不默认采用。

删除服务器配置、清除本地秘密、清除浏览器偏好和在供应商撤销 Key 是不同操作。备份必须受访问控制并加密，密文和主密钥分别管理；数据库备份成功不等于秘密可恢复。备份恢复和密钥轮换须独立演练。

接入使用专门假值或测试凭据，验证：必填缺失与格式错误；就绪失败不替换健康旧版；源码、构建、日志及下载不出现测试秘密；匿名及其他所有者管理被拒；同步幂等与冲突；掩码不覆盖；更新和重启保留配置；指定修订生效及回滚；撤销不被回滚绕过。环境注入的进程内旧值按第 4 节处理。秘密与主密钥恢复、真实供应商调用分别验收。

报告区分本地保存、服务器保存、发布绑定、运行生效、上游业务验证。默认采用不产生业务费用的检查，真实付费调用按用户授权；格式检查和假值测试不能证明真实服务商可用。
