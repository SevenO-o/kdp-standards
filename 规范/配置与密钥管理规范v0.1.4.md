# 配置与密钥管理规范 v0.1.4

继承 [v0.1.3](配置与密钥管理规范v0.1.3.md) 的取值顺序、隐藏输入、中断恢复、加密存储与后端环境注入规则；本版替代其中仅限原生 HTTPS 主入口的要求。

## 助手专用连接

维护者可在同服务器开启独立 HTTPS API，同时保留网页和工具的 HTTP 地址。公司安装包提供 `api-transport.json`，包含固定的 HTTPS 地址及公开证书，安装器写入用户的可信 bootstrap。证书仅用于助手 API 请求，不写入系统或浏览器 CA，不来自工具源码、工具环境或服务器动态响应。

助手校验证书有效期、IP、证书链与固定平台主机，所有发布 API 请求均走该连接；拒绝重定向，失败不回退 HTTP，拒绝关闭 TLS 校验的环境。发布者凭据继续绑定原平台来源，升级助手不更换所有者。

首次安装包必须由公司可信渠道取得并核对维护者给出的摘要；公开下载地址本身不建立信任。证书更新需维护者分发并安装新包，不自动信任服务端返回的新证书。

## 使用方式

继续执行 `kdp publish --project /工具目录`。缺少必填 Key 时终端隐藏输入；服务器保存后在后续发布中复用，仅注入对应工具的后端运行环境，不作为整台服务器的全局环境配置。工具仍用 `process.env.TOOL_API_KEY` 读取。

没有专用连接配置时仍可使用经正常验证的原生 HTTPS。仅有 HTTP 的旧助手会在输入前拒绝同步 Key。其他权限、幂等性、修订、撤销、回滚、构建隔离和可选目标代理规则保持不变。
