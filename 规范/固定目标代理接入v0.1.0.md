# 固定目标代理接入 v0.1.0

属于规范包 0.1.8。仅在业务明确需要固定目标、平台计数和代理注入时使用；默认后端环境注入不受本页 JSON、固定路径与代理次数限制。

## 1. 接入方式

配置修订绑定目标与秘密版本。已绑定目标的秘密只供代理使用，不注入工具环境；工具后端持有发布专属签名上下文及代理地址，由平台校验后在 HTTPS 请求头注入秘密。不得提供任意密钥读回接口。

普通配置仍从后端环境读取。`KDP_CONFIG_REVISION_ID`、`KDP_RELEASE_ID`、`KDP_BROKER_URL` 为平台元数据；`KDP_BROKER_CA` 是仅验证代理 TLS 的公开证书，`KDP_CONTEXT_SECRET` 只在后端用于独立用途的签名，不能暴露给浏览器或第三方。

管理连接、加密保存、修订、撤销和验收共同遵循 [配置专项](配置与密钥管理规范v0.1.5.md)。切换环境注入与代理模式时显式调整目标绑定和业务代码，不能自动把代理秘密注入环境。

## 2. 所有者同步与生效

以下为明确选择固定目标代理或高级配置维护时的操作；日常环境注入发布见 [配置专项](配置与密钥管理规范v0.1.5.md)。先执行助手 `help` 并核对能力。高级配置文件由用户在私密编辑器中填写，位于项目之外、权限 0600，不把值交给聊天，不同步整份环境。

首次可先登记工具，不构建或启动容器：

```sh
kdp config --project /工具目录 --new-tool
kdp config --project /工具目录
```

已有工具绑定丢失时使用 `--restore TOOL_ID`，不能重新登记身份或新建同名工具绕过归属。连接配置由可信安装管理，不手改凭据来源。

私密输入文件结构（仅假值说明，真实值由私密输入路径提供）：

```json
{
  "environment": "production",
  "expectedConfigRevisionId": null,
  "config": { "TOOL_MODEL": "example-model" },
  "secrets": {},
  "targets": [{
    "id": "generate",
    "url": "https://api.example.com/v1/generate",
    "method": "POST",
    "secretName": "TOOL_API_KEY",
    "header": "authorization",
    "prefix": "Bearer ",
    "requestsPerMinute": 5,
    "requestsPerDay": 100,
    "concurrency": 1
  }]
}
```

上例故意省略秘密；首次保存必填秘密时必须通过私密输入补齐，否则平台拒绝。更新时省略秘密表示沿用当前版本。目标数组每次完整提交，改地址、方法或密钥关系都应在本次授权范围内明确列出。`expectedConfigRevisionId` 使用读到的服务器基础版本；冲突时重新读取、按字段合并，不自动覆盖。

```sh
kdp config --project /工具目录 --input-file /私密目录/change.json --operation-id 同步操作编号
kdp publish --project /工具目录 --config-revision cfg_返回的编号
kdp config --project /工具目录 --activate cfg_返回的编号 --operation-id 激活操作编号
kdp status --release rel_返回的编号
kdp config --project /工具目录 --revoke-version sec_待撤销编号 --operation-id 撤销操作编号
```

操作编号使用 8—128 位 ASCII 字母、数字、连字符或下划线；上述中文为解释占位符。保存响应是 `saved / activation: pending`；激活响应是 `queued`，必须查询发布结果确认是否生效。首次声明配置需要发布代码镜像；之后相同声明的配置变化可免构建激活。失败保持旧版。回滚恢复目标发布绑定的配置，已撤销秘密不可恢复；可先保存替换秘密的新配置修订，再激活到当前镜像。

同步中断后保留原输入文件与相同操作编号重试。不要修改该文件后复用原编号。激活助手会先保存预期当前发布，响应丢失仍使用同一请求；不能看到网络超时就生成另一个操作。

## 3. 受控上游范围

目标使用完整、规范化的 HTTPS 域名与固定路径，只支持 443 端口、GET / POST、JSON 请求与响应；不接收动态 URL、查询参数、重定向或工具自带授权头。头名称限 `authorization`、`x-api-key`、`api-key`，前缀限空字符串或 `Bearer `。API Key 只能绑定 `secrets` 中的名称。

平台逐次解析并固定已验证的公开 IPv4，拒绝回环、私有、链路本地、共享地址、保留地址及混合 DNS 结果；当前不支持 IPv6。保持原域名的 TLS 校验，禁止代理环境变量改变连接。上游错误、非 JSON、重定向和可识别的密钥反射不会转交工具。

上游请求体最多 1 MiB，响应最多 8 MiB；DNS 最多 5 秒，HTTP/TLS 最多 25 秒。工具请求必须签名并带 30 秒内时间戳和唯一 nonce；只允许当前成功发布调用。已登记的 nonce 不重复调用上游，网络结果不明时不得自动重试。配额为工具共享的滚动 1 分钟 / 24 小时请求数，所有目标共用最严格限制；每工具并发最多 4，全平台最多 4。失败、超时同样消耗请求额度；换版本或增设目标别名不能清零计数。

请求次数不是费用上限。工具业务接口必须校验模型、图片数量、尺寸、token 上限等影响费用的参数；不得把此代理不加业务限制地开放为通用转发。真实付费请求仍须取得适用授权。

## 4. 后端接入与边界

在后端实现下面的签名客户端；本文件附录提供完整参考。调用时只传目标 ID 和业务 JSON，禁止把浏览器传来的地址、Header 或签名上下文透传进去。普通配置可从 `process.env.TOOL_MODEL` 读取。

```ts
const result = await requestConfiguredUpstream('generate', {
  model: process.env.TOOL_MODEL,
  prompt: validatedPrompt,
  n: 1
});
```

工具就绪检查应验证必填普通配置、格式和三个平台代理元数据；共享秘密的缺失、撤销由平台在保存、绑定、激活及每次代理调用时拦截。不得在就绪检查中触发付费请求。只支持 JSON 形式的上游协议，尚不提供 multipart、流式输出、动态任务轮询 URL、任意签名算法或任意供应商 SDK 适配；按具体供应商独立补充并验收。

API 进程能解密秘密，执行器数据库角色不能读取密文列；工具进程只持有该发布的代理访问能力。秘密撤销后新请求立即被拒绝，已经获准并发送的请求可能完成。撤销平台秘密版本不等于在供应商撤销 Key。批准的第三方仍是接收密钥的信任边界；不能把反射检测宣称为对恶意第三方变形泄密的完整防护。

普通工具开放联网不变。这里限制的是携带平台秘密的请求，不是整机出口防火墙，也不宣称完成恶意工具代码的多租户隔离。备份恢复、主密钥恢复、真实供应商业务验证各自独立验收。

## 附录：仅后端的参考客户端

```ts
import { createHmac, randomBytes } from 'node:crypto';
import { request, Agent } from 'node:https';

/** Backend only. The platform adds the provider secret; the tool never receives
 * it. No automatic retry: an ambiguous result may have consumed paid quota. */
export async function requestConfiguredUpstream(targetId: string, body?: unknown): Promise<unknown> {
  if (process.env.NODE_TLS_REJECT_UNAUTHORIZED === '0') throw new Error('KDP_TLS_VERIFICATION_REQUIRED');
  const { KDP_BROKER_URL: endpoint, KDP_RELEASE_ID: releaseId, KDP_CONTEXT_SECRET: key } = process.env;
  if (!endpoint || !releaseId || !key || !process.env.KDP_CONFIG_REVISION_ID) throw new Error('KDP_CONFIGURATION_UNAVAILABLE');
  const url = new URL(endpoint);
  if (url.protocol !== 'https:' || url.username || url.password || url.pathname !== '/runtime/v1/egress' || url.search || url.hash) throw new Error('KDP_BROKER_INVALID');
  const input = { releaseId, targetId, timestamp: Date.now(), nonce: randomBytes(16).toString('hex'), body: body === undefined ? '' : JSON.stringify(body) };
  const signature = createHmac('sha256', key).update('kdp-egress-v1\n').update(JSON.stringify(input)).digest('hex');
  return new Promise((resolve, reject) => {
    const agent = new Agent({ keepAlive: false });
    const req = request(url, { method: 'POST', agent, rejectUnauthorized: true,
      ...(process.env.KDP_BROKER_CA ? { ca: Buffer.from(process.env.KDP_BROKER_CA, 'base64') } : {}),
      headers: { 'content-type': 'application/json', 'x-kdp-signature': signature },
    }, res => {
      if (!res.statusCode || res.statusCode < 200 || res.statusCode >= 300) {
        reject(new Error(`KDP_UPSTREAM_REJECTED_${res.statusCode}`)); res.destroy(); req.destroy(); return;
      }
      let size = 0; const chunks: Buffer[] = [];
      res.on('data', (chunk: Buffer) => {
        size += chunk.length;
        if (size > 8 * 1024 * 1024) { reject(new Error('KDP_UPSTREAM_RESPONSE_TOO_LARGE')); res.destroy(); req.destroy(); }
        else chunks.push(chunk);
      });
      res.on('error', () => reject(new Error('KDP_UPSTREAM_OUTCOME_UNKNOWN: do not automatically retry')));
      res.on('end', () => { try { resolve(JSON.parse(Buffer.concat(chunks).toString('utf8'))); } catch { reject(new Error('KDP_UPSTREAM_INVALID_RESPONSE')); } });
    });
    const timer = setTimeout(() => { reject(new Error('KDP_UPSTREAM_OUTCOME_UNKNOWN: do not automatically retry')); req.destroy(); }, 35000);
    req.on('error', () => reject(new Error('KDP_UPSTREAM_OUTCOME_UNKNOWN: do not automatically retry')));
    req.on('close', () => { clearTimeout(timer); agent.destroy(); });
    req.end(JSON.stringify(input));
  });
}
```
