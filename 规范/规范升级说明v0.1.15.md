# 规范 0.1.15 升级说明

目标组合 `kdp-0.1.15-ts-web-0.1.7-checker-0.1.16`。只有 [框架开发约定](框架开发约定v0.1.1.md) 必读，参数查 [接口与运行参考](接口与运行参考v0.1.1.md)。

## 变化

- HTTP v2 将普通接口与文件传输分开：普通接口仍为 8 MiB；文件双向流式转发，默认 256 MiB，可配置或取消文件字节上限，同时保留超时、并发和取消。
- 平台和本地网关保持共享实现。新增共享 policy 副本供浏览器使用，避免将 Node 传输代码打包进前端。下载中断不会产生成功 Blob 或虚假统计。
- 配套能力接口提供实际策略；调整平台配置后，本地验证应使用相同参数。模板业务服务自身的文件解析器、内存和超时仍按业务需求设置。
- 规范阅读结构及检查器 11 项流程保持，无新增独立文件工具必读规范。Skill / 助手机制不变，可复用独立 Skill 0.1.4。

## 已有工具

获得升级授权后，以新组合初始化对照目录，保留原身份、工具绑定、业务和未提交改动，合并完整规范锁、shared、scripts 和 web/lib/http.ts。不要在旧版本锁下只改平台适配代码。

先确认新平台已部署 HTTP v2，再验大于 8 MiB 的文件、超限、取消、错误响应及真实下载结果。工具自身原有 8 MiB 限制不会因平台升级自动消失，需按实际业务调整。发布和已有工具升级仍需相应授权。
