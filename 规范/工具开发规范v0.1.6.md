# 工具开发规范 v0.1.6

继承 [v0.1.5](工具开发规范v0.1.5.md) 的配置、后端环境注入、前端及运行契约，新增发布时命令交互输入。涉及配置或 Key 时读取 [配置与密钥管理规范 v0.1.3](配置与密钥管理规范v0.1.3.md)。

工具声明的必填字段在本地和服务器都缺少时，支持交互的发布助手在终端提示填写，输入不回显，完成后继续原发布流程。无需新增工具业务代码或设置页面。已有环境值和服务器配置优先复用，声明、接口与运行注入格式不变。

本能力需要新版发布助手；规范版本本身不会更新已安装客户端。无终端时报告 `CONFIG_INPUT_REQUIRED`，由用户在自己的交互终端执行同一条命令，或配置本地环境后重试。Agent 不得索要 Key 的聊天输入，也不能将 Key 放入命令参数。

本版为本地候选，服务器部署仍暂停。本次只增加输入方式，未实现此前讨论的保留 HTTP 入口的新加密传输方案，继续执行现有配置通道校验。
