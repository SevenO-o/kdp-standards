# 工具开发规范 v0.1.5

本版继承 v0.1.3 的前端、文件及联网契约，调整 v0.1.4 本地候选的密钥接入方式：默认使用后端环境变量，随发布自动同步。具体要求见 [配置与密钥管理规范 v0.1.2](配置与密钥管理规范v0.1.2.md)，本版覆盖此前要求所有秘密必须走平台代理的条款。

工具在 `kdp.json` 的 `config`、`secrets` 中声明名称与 `required`，格式不变。后端通过 `process.env.TOOL_*` 读取配置和密钥。开发时在当前环境或项目 `.env.local` 配置；发布助手自动同步已声明值并绑定确切配置修订。无需设置页面、额外 JSON 文件或手动填写修订编号。`.env.local` 不进入源码包、Git 或镜像。

本地后端需要加载环境文件，例如 Node.js 24 启动时使用 `--env-file-if-exists=.env.local`；当前进程环境优先。Vite 的前端变量不能用于密钥，禁止 `VITE_*` 暴露秘密。就绪检查验证必填值和格式，不发起付费请求；离线检查、测试和镜像构建不依赖真实 Key。

启用条件为可信平台原生 HTTPS、`configuration.enabled=true`、`configuration.injection=environment-v1` 及配套助手。本版是本地候选，下载到规范不代表服务器已经具备能力。

普通 SDK 和后端 HTTPS 请求继续使用现有开放出口。固定目标平台代理保留为可选方式，已有显式目标绑定的秘密继续只供代理使用；不自动改为环境注入。无配置旧工具不受影响，旧组合保留，已有工具不自动升级。镜像和配置版本共同回滚；撤销版本不能再次发布、激活或恢复。
