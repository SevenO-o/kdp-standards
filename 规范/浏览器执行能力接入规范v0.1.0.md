# 浏览器执行能力接入规范 v0.1.0

网页采集、动态页面解析、网页截图、浏览器渲染 PDF 及其他依赖真实浏览器的工具按需必读。通用要求见 [主规范](工具开发规范v0.1.10.md)，运行验证见 [运行兼容规范](运行环境与依赖兼容规范v0.1.1.md)，下载和临时结果见 [文件专项](文件上传与下载规范v0.1.3.md)。

## 1. 当前能力与开发前检查

本版规定接入和验收要求，**不代表平台已经交付浏览器执行服务**。当前默认 ts-web 镜像未预装 Chromium，标准工具限额为 256 MiB、0.5 CPU、128 个进程或线程，临时目录为 32 MiB；构建无网络，根目录只读。安装 Playwright/Puppeteer 的 npm 包不等于浏览器及系统依赖已进入最终镜像。

开发前必须列出实际执行路径：普通 HTTP/API 是否足够，是否需要 JavaScript 渲染、登录会话、滚动、下载或交互。需要浏览器时先取得维护者提供的可用服务、支持操作、接入契约及目标验证证据，再承诺服务器采集能力。已有工具也在相关功能新增或依赖变更时执行此检查。

| 状态 | 开发和交付要求 |
| --- | --- |
| 目标平台尚无浏览器能力或未确认 | 完成本地业务、测试用例和缺口说明；目标结果记为 `notRun`，不得报告服务器采集可用 |
| 已有获准服务，目标网站未验收 | 按实际契约适配并执行目标业务用例；服务连通、浏览器启动不能代替采集成功 |
| 同一候选和目标网站业务已验收 | 在验证过的输入、并发、会话和资源边界内交付，注明验收日期和限制 |

页面、任务 API 和普通健康检查成功，不能把上述前两种状态改成第三种。若交付的是界面演示，必须明确标为演示；业务页面用可理解的说明告知“采集暂不可用”，不展示虚假进度、完成状态或示例图片冒充真实结果。

## 2. 执行方案与职责

平台扩展浏览器能力优先采用维护者管理的独立执行服务：工具前端 → 工具后端 → 受控执行接口 → 浏览器任务 → 结果。普通工具继续使用标准 Node 镜像和资源限制，浏览器服务独立管理镜像、资源及生命周期。

- 维护者在受控镜像准备阶段预装精确版本的浏览器、客户端/执行程序、字体和系统依赖，验证来源与完整性，按镜像摘要部署。准备和分发属于平台维护流程；不能将平台工具构建改为联网，也不能让工具启动时下载二进制。
- 工具负责业务输入校验、调用服务、展示真实任务状态、校验和交付结果。服务负责执行鉴权、队列与并发、浏览器沙箱、任务隔离、资源控制、超时、回收和清理。
- 当前没有通用浏览器 SDK、能力发现端点、自动授权流程或可直接使用的统一任务 API。本页不定义可调用 URL、SDK 名称或现成命令；实际接入以前置验收后的版本化接口契约为准。不能给 `kdp.json` 增加 `browser`、Docker 参数、CPU 或内存字段来申请能力。
- 获准服务可以通过既有 `TOOL_` 配置/秘密名称和后端环境注入接入，遵循 [配置专项](配置与密钥管理规范v0.1.7.md)。这不表示平台已自动发放凭据。不得将浏览器控制地址和凭据交给页面，也不得用发布凭据、平台 Cookie 或上下文签名密钥连接服务。
- 远程浏览器连接只是传输方式，不能直接把无鉴权的调试端口作为公共服务。优先提供受限任务接口；提供远程控制时，仍须经过鉴权、会话隔离、限额与访问目标控制，不接受任意宿主命令或挂载。

替代方案如独立运行档位或已批准的外部浏览器服务，须先完成对应的镜像、资源、鉴权、数据流向和目标业务验收。普通工具不得自行改变基础镜像、运行参数或部署额外服务。

## 3. 接口与任务生命周期要求

正式接入契约至少说明以下内容；下表是待实现服务的要求，**不是当前平台 API 字段或端点**。工具 API 仍使用主规范的响应和错误格式，通过自身 Schema 生成类型。

| 范围 | 契约必须说明 |
| --- | --- |
| 输入 | 支持的操作、目标 URL、页面/滚动/结果数量上限、业务参数、幂等标识及禁止输入 |
| 任务身份 | 不透明任务 ID、所属工具与获准会话；查询、取消和下载逐次校验归属，不仅依赖 ID 难猜 |
| 状态 | 排队、执行中、成功、失败、取消、超时；状态转换、终态定义和重启后行为 |
| 重试 | 提交结果未知先查询或复用幂等标识；仅对可重试故障有限重试，限制总耗时和次数 |
| 结果 | 元数据、来源页面、输出格式/数量/大小、部分成功语义、下载授权及失效时间 |
| 错误 | 区分能力不可用、服务鉴权失败、输入无效、目标需登录/验证、目标访问受限、排队超限、超时、资源不足和解析失败；不暴露 Cookie、内部地址、堆栈或页面私密内容 |
| 停止与清理 | 取消、客户端断开、工具下线、服务重启时如何终止或继续，何时清理会话、临时文件及结果 |

不能无限轮询、无限重试或每次重试新建一份任务；目标网站要求人工登录或验证时明确返回该状态。采集条目必须来自真实目标结果；合法空结果须有明确语义，不能吞掉解析失败后返回空列表并判为成功。

首版可使用有界、可丢弃的临时任务，但必须说明重启会丢失、有效期及失败恢复方式，不承诺可靠续跑。跨重启恢复、长期保存任务或图片需要另行交付持久能力，不能借浏览器服务隐式开放业务数据库或文件存储。

## 4. 资源、网络与会话隔离

维护者按真实目标页面确定浏览器服务内存、CPU、进程/线程、私有共享内存、可写临时空间、队列长度、单任务时限和并发上限。先以并发 1 测量冷启动、真实采集及峰值，再决定配额；本规范不把未经目标实测的内存/CPU 建议写成保证值。

独立容器仍消耗所在宿主和引擎资源，容量核算应包含现役工具、候选构建和浏览器峰值。引擎聚合限额与单服务限额分别核对，不为运行浏览器扩大所有工具限额。服务镜像另验目标 CPU、架构、libc 和浏览器版本兼容，远程客户端与执行端按所用协议要求锁定兼容版本。

浏览器访问外部页面使用经验证的非 root 与沙箱方案、独立可写目录和资源限制；不把 `--no-sandbox`、特权容器、宿主 IPC/网络或挂载 Docker socket 作为默认接入手段。维护者提供目标引擎下可工作的隔离证据；工具不能擅自放宽宿主策略。

服务分别校验维护者配置的服务目标与用户提交的网页 URL。用户网页 URL 仅允许获准协议和目标，校验 DNS 解析、跳转链及页面触发的子资源/下载请求，阻止访问回环、内网、链路本地、元数据和平台管理地址；不能只校验第一次导航。内网站点采集如确有业务需要，由维护者限定目标授权，不允许用户输入绕过边界。

平台允许工具外连，不代表任意目标网站都可访问或可采集。DNS/TLS、出口、目标网站登录与页面交互分别验收；不得通过忽略证书校验或无限重试掩盖问题。

默认使用一次性浏览器上下文，会话和结果按工具、任务及获准身份隔离。`intranet-visitor` 不能作为不同使用者的个人会话隔离键。个人 Pinterest 等站点的 Cookie、密码和浏览器存储不能直接作为共享工具配置供所有访客使用；没有可信个人身份与会话授权机制时，不交付个人登录采集。确需工具共享账号时须明确共享范围、获准使用者和访问控制，不能默认将发布者账号交给匿名访客。

站点凭据不得进入源码、日志、前端、截图报告或通用任务响应。若需要持久登录状态，须有专门的加密存储、访问控制、撤销及清理契约；普通临时目录不构成持久会话能力。

## 5. 目标验收与交付证据

业务测试与平台验证分层记录，不因没有目标浏览器而删除相关用例或用 mock 代替真实目标结果。

1. **本地业务**：校验输入、任务状态、结果处理和错误提示；mock 可测接口分支，但报告明确模拟范围。
2. **最终执行镜像**：在目标 CPU、镜像、用户、沙箱及有效限额下冷启动浏览器，访问受控测试页面，完成真实渲染、交互和输出；运行期间不临时安装。核验服务鉴权、跨工具/会话拒绝和目标网络限制。
3. **真实目标**：使用已获准的目标页面和登录方式，执行实际操作。例如 Pinterest 参考图采集必须打开目标、执行声明的滚动/加载、提取真实条目，并验证图片获取和工具侧交付；如只交付链接，则验证链接与元数据而不宣称图片已下载。打不开、需登录、验证码、访问限制和解析变化分别记录。
4. **资源与故障**：验证声明最大输入、并发和超时，记录内存/CPU、进程和临时空间峰值；验证队列满、取消、客户端断开、执行失败和服务重启后的状态及清理。单页成功不能证明批量或多用户能力。
5. **发布与恢复**：工具候选与实际服务版本绑定记录，更新、故意失败保留旧版、回滚及权限按发布流程验收；服务变更另行核对现役工具。必要服务未配置或已知不兼容时就绪失败；健康轮询仅做有界依赖检查，不反复访问真实目标网站、执行采集或触发收费。

README/验收记录写明日期、工具源码与镜像摘要、浏览器服务镜像/契约/客户端版本、脱敏目标环境与有效配额、用例、真实结果、峰值、清理结果及限制。`local` 与 `targetRuntime` 分别记录 `passed`、`failed` 或 `notRun`，未测项列出原因，不写入平台锁伪造能力。

当前检查器仍只执行本地检查，浏览器能力发现、自动预检与发布自动门禁尚未实现。无目标证据时可以交付本地源码或明确的演示结果，不能报告该核心业务已在服务器验收可用。维护者部署浏览器服务与升级工具须另在对应授权范围内执行。
