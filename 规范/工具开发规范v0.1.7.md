# 工具开发规范 v0.1.7

继承 [v0.1.6](工具开发规范v0.1.6.md) 的发布时交互输入与环境注入契约。本版增加助手专用加密连接，涉及 Key 时读取 [配置与密钥管理规范 v0.1.4](配置与密钥管理规范v0.1.4.md)。

工具及网页仍使用公司配置的公开入口。助手可通过安装包内置的同服务器 HTTPS 连接发布，证书仅在助手请求中生效。开发者照常执行发布命令，工具通过后端环境变量读取声明的 Key；无需安装系统 CA 或自行传输 Key。旧助手未配置加密连接时仍不能通过 HTTP 同步秘密。

这是兼容组合的新版本，不自动迁移或重新部署已有工具；锁定旧组合仍可按其原契约使用。
