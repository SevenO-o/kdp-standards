# KDP 规范包阅读入口

本规范包版本为 `0.1.7`。项目使用哪个版本，以 `kdp.lock.json` 和公司可信索引为准；本地源码和候选包存在不表示服务器已经支持该组合。

1. 先读 [工具开发规范 v0.1.7](工具开发规范v0.1.7.md) 和 [工具开发规范 v0.1.3](工具开发规范v0.1.3.md)，了解发布时交互输入与配置同步、统一主题、公共组件和页面结构范围；所有本组合的工具前端必须读 [前端界面规范](前端界面规范v0.1.0.md)。
2. 再读 [工具开发规范 v0.1.2](工具开发规范v0.1.2.md) 的运行联网规则与 [工具开发规范 v0.1.1](工具开发规范v0.1.1.md) 的访问模式和检查边界。
3. 继承 [工具开发规范 v0.1](工具开发规范v0.1.md) 与 [发布接口规范 v0.1](发布接口规范v0.1.md) 中未被明确替代的契约。旧版本文件保留原字节；冲突以本版明确修订为准。
4. 涉及文件输入或输出，必须读 [文件上传与下载规范](文件上传与下载规范v0.1.0.md)。
5. 涉及持久配置、第三方服务或 API Key，必须读 [配置与密钥管理规范](配置与密钥管理规范v0.1.4.md)。

这些文件共同组成规范 0.1.7，不能只复制专项或修改锁文件冒充升级。旧规范引用的维护仓库文档可能不包含在分发包中，不要求工具 Agent 向父目录寻找。新建项目和旧工具迁移均通过可信来源取得完整兼容组合；没有自动升级已有工具。
