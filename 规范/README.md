# KDP 工具开发入口

组合：规范 **0.1.15** / 模板 **ts-web 0.1.7** / 检查器 **0.1.16**。实际项目使用 `kdp.lock.json` 中的锁定组合；本地候选不代表服务器已支持。

**只需先读 [框架开发约定](框架开发约定v0.1.1.md)。** 使用模板的前后端框架与公共模块，主要编写业务逻辑，并通过平台方式验证结果。

- 需要查接口、文件、配置、构建或资源参数时，查 [接口与运行参考](接口与运行参考v0.1.1.md) 的相关章节，不必通读。
- 明确升级已有工具时，读 [升级说明](规范升级说明v0.1.15.md)。普通业务更新保持原锁。
- 组件用法和开发示例在项目 `web/components/README.md`、`docs/可选能力接入.md`；服务器运维和历史故障不属于工具开发必读材料。

平台负责发布隔离、资源准入、身份与网关；模板负责通用请求、错误、下载、主题与开发预览；工具负责真实业务结果。目标是尽早发现本地与服务器差异，不承诺跳过目标环境验证也能保证所有依赖和外部网站正常。
