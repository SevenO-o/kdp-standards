# KDP 规范包阅读入口

本包为完整规范 **0.1.8**，配套模板 **ts-web 0.1.4**、检查器 **0.1.9**、平台 API **v1**。实际采用版本以项目 `kdp.lock.json` 为准；本地候选不代表公开索引或服务器已支持。

1. 所有工具先读 [工具开发规范](工具开发规范v0.1.8.md)，再读 [前端界面规范](前端界面规范v0.1.1.md)。主规范已合并当前有效要求，无需追溯历史修订。
2. 有文件输入或输出，读 [文件上传与下载规范](文件上传与下载规范v0.1.1.md)。
3. 有工具共享配置或 API Key，读 [配置与密钥管理规范](配置与密钥管理规范v0.1.5.md)。默认走后端环境注入；仅明确选择固定目标代理时继续读 [固定目标代理接入](固定目标代理接入v0.1.0.md)。
4. 发布、更新、回滚或管理工具时，读 [发布与生命周期接口规范](发布接口规范v0.1.1.md)，通过已安装助手执行。
5. 明确升级已有工具时，读 [规范升级说明](规范升级说明v0.1.8.md)。普通业务更新保持原锁。

主规范定义通用要求，专项补充对应业务的具体限制；本包没有逐版覆盖链。规范要求、检查器自动检查、平台支持与实际业务验收分别判断，缺少能力不能靠修改声明绕过。

历史规范和产物留在维护记录与原版本归档中，不属于本包阅读路径。Skill 是独立稳定入口，常规规范更新无需重装；新项目由助手获取推荐组合，旧项目不会自动迁移。
