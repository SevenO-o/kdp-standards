# KDP 工具开发规范与材料

本仓库提供开发工具时使用的前后端规范、接口契约、标准模板、检查器和版本索引。无需 GitHub 账号、登录或邀请即可读取和拉取。

## 2026-09-15 开发材料发布

规范 **0.1.15 / ts-web 0.1.7 / 检查器 0.1.16** 已公开。平台与本地模板共用 HTTP v2：文件上传、下载流式传输，默认每方向 256 MiB，平台可配置为其他值或 0（取消文件大小上限）；普通接口保持 8 MiB，文件默认 300 秒、每网关进程并发 4。完整本地检查仍为 11 项。

**平台已配套部署并通过真实发布、更新、失败保护、回滚及大文件传输验收。** 新项目可以取得本组合开发和发布；已有工具保持原锁，不会自动升级。网关放宽对已有入口生效，工具自身的文件解析器和大小限制仍需按业务验证。本地验收采用与目标平台相同的自定义参数；助手默认检查不自动同步远端配置。

继续使用维护者单独交付的 **Skill 0.1.4**，已验证能获取、初始化并检查本组合，无需重新安装。本仓库只分发开发材料。归档中的准备阶段说明不代表当前部署状态，以本节为准。
