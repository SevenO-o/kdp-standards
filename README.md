# KDP 工具开发规范与材料

本仓库提供开发工具时使用的前后端规范、接口契约、标准模板、检查器和版本索引。无需 GitHub 账号、登录或邀请即可读取和拉取。

## 2026-09-15 开发材料发布

规范 **0.1.14 / ts-web 0.1.6 / 检查器 0.1.15** 已公开。统一前后端框架，提供共享网关、本地生产方式预览和公共文件指标处理；完整本地检查为 11 项。

**平台已配套部署并通过真实发布、更新、失败保护、回滚及浏览器验收。** 新项目可以取得本组合开发和发布；已有工具保持原锁，不会自动升级。默认 Node 基础镜像已按官方摘要预置；服务器直连 Docker Hub 仍受出口限制，其他基础镜像须确认可拉取或由维护者按摘要预置。

本版需要维护者单独交付的 **Skill 0.1.4** 配套助手，以正确打包新增的 `shared/` 目录；旧助手需要更新。本仓库继续只分发开发材料。归档中“本地候选”的说明记录准备时状态，当前公开分发状态以本节为准。

**Skill 由维护者另行打包分发。** 本仓库不提供 Skill、助手安装包或安装入口。安装 Skill 后，直接描述工具需求，由 Skill 自动从这里获取适用的开发材料。

```sh
git clone https://github.com/SevenO-o/kdp-standards.git
```

可浏览的规范与模板来自推荐版本的归档。开发时通过已安装助手获取完整版本组合并验证摘要，以项目 `kdp.lock.json` 为准。
